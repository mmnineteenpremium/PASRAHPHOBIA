| Server Command Bar | Window `Server` saat local multiplayer | Bisa mengakses semua `Players`, `ServerScriptService`, server state. Tidak boleh dipakai untuk mengubah permanent authored UI. |
| Client Command Bar | Window client terpilih | Bisa mengakses `Players.LocalPlayer`, `PlayerGui`, camera, local UI/runtime. Perubahan hilang saat Stop Play. |

## Checklist Aman Sebelum Menjalankan Command

1. Pastikan mode benar: Edit Mode, Play Solo, Server Command Bar, atau Client Command Bar.
2. Jika script menyebut `Players.LocalPlayer`, jalankan di Client Command Bar.
3. Jika script menyebut `ServerScriptService` atau semua player, jalankan di Server Command Bar/Edit Mode.
4. Untuk object sementara, selalu pakai prefix `OWNER_TEMP_`.
5. Setelah test, jalankan cleanup row 40 dan row 41.
6. Setelah perubahan manual yang ingin disimpan, tekan `Ctrl+S` dan tunggu minimal 60 detik.
7. Jangan edit `ServerScriptService`, `StarterPlayerScripts`, `RemoteEvent`, `RemoteFunction`, atau module logic secara manual kecuali memang sedang diarahkan agent.
