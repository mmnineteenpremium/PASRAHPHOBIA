PASRAHPHOBIA - HUNT STATE MACHINE

OVERVIEW

The Hunt State Machine defines the internal logic of a ghost hunt event.

States

Preparing
Active
Chasing
Ending

STATE: PREPARING

Hunt initialization.

Actions

Doors lock
Lights flicker
Ghost becomes visible

Transition

PreparationComplete → Active

STATE: ACTIVE

Ghost begins searching for players.

Transition

PlayerDetected → Chasing
HuntTimerExpired → Ending

STATE: CHASING

Ghost actively pursues a target player.

Transition

TargetLost → Active
PlayerKilled → Active
HuntTimerExpired → Ending

STATE: ENDING

Hunt ends.

Actions

Doors unlock
Lights stabilize
Ghost disappears

Transition

Return → Investigation
