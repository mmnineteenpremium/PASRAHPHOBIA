# TASK & PHASE PLAN — HAUNTED HOUSE (PLACE 1)

Status: Pending approval per phase.

## Phase 0 — Setup (Prerequisite)
- Create folder structure for assets and logs.
- Confirm Place 1 is clean and active.

## Phase 1 — Outdoor: Base Layout
- Blockout terrain footprint and playable boundary.
- Define main path from gate to front door.
- Establish outer perimeter tree line and sight-blocking.
Acceptance criteria:
- Path readability from spawn to house.
- Clear silhouette of house area with open sightlines.

## Phase 2 — Outdoor: Exterior Massing
- Build exterior shell (rooflines, porch, veranda).
- Place key exterior props (fence, gate, graveyard).
Acceptance criteria:
- House reads as main focal point from spawn.
- Exterior composition is believable and not cluttered.

## Phase 3 — Outdoor: Lighting & Atmosphere
- Night lighting setup (moonlight, porch, path lights).
- Atmosphere, fog, and color correction pass.
Acceptance criteria:
- House silhouette readable at night.
- No over-dark areas that hide key navigation.

## Phase 4 — Outdoor: Detail Pass
- Add foliage variation, debris, small props.
- Balance density to avoid occlusion.
Acceptance criteria:
- Outdoor feels lived-in and “haunted,” not empty.
- Navigation remains clear for players.

## Phase 5 — Indoor: Room-by-Room (Sequential)
Rooms will be done one at a time with approval after each.
Example order:
1. Foyer / Entry
2. Living Room
3. Dining Room
4. Kitchen
5. Study
6. Bathroom 1
7. Stair Hall
8. Upper Hall
9. Master Bedroom
10. Guest Bedroom
11. Nursery
12. Bathroom 2
13. Attic Access / Storage
Acceptance criteria (per room):
- Clear layout and believable prop placement.
- Navigation readable and not cluttered.

## Phase 6 — Wiring: Interaction & Trigger Props
- Place lamps, doors, wardrobes, TV, movable props.
- Tag and prepare parts for ghost events.
Acceptance criteria:
- Each interactive prop has clear purpose and placement.
- No overlaps or ambiguous trigger areas.

## Phase 7 — Systems Wiring (Logic)
- Event hooks for flicker lights, door open, TV on, falls, jumpscare triggers.
Acceptance criteria:
- Wiring is consistent and testable.

## Phase 8 — Integration & Optimization
- StreamingEnabled readiness.
- LOD/low poly fallback where needed.
Acceptance criteria:
- Acceptable performance in playtest.
