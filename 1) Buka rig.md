**1) Buka rig**



&#x20; **1. File > Open**

&#x20; **2. Pilih HANDY\_HANDS\_RIG\_PREVIEW.blend.**



&#x20; **2) Pilih armature**



&#x20; **1. Di panel kanan atas (Outliner), klik object HandyHandsRig.**

&#x20; **2. Di viewport, pastikan objek armature terpilih (outline kuning).**



&#x20; **3) Masuk Edit Mode (untuk pindah posisi bone)**



&#x20; **1. Di kiri atas viewport ada dropdown mode (Object Mode).**

&#x20; **2. Klik dropdown itu → pilih Edit Mode.**

&#x20;    **(Shortcut: Tab).**



&#x20; **4) Tampilkan tulang dengan jelas**



&#x20; **1. Di kanan (panel Properties) klik tab Object Data Properties (ikon tulang hijau).**

&#x20; **2. Di section Viewport Display, centang In Front supaya tulang terlihat menembus mesh.**



&#x20; **5) Pilih bagian bone yang mau digeser**



&#x20; **- Di Edit Mode:**

&#x20;     **- klik ujung bawah bone = Head**

&#x20;     **- klik ujung atas bone = Tail**

&#x20;     **- klik garis bone = seluruh bone**

&#x20; **- Gunakan:**

&#x20;     **- G = geser bebas**

&#x20;     **- X, Y, Z setelah G = kunci sumbu**

&#x20;       **contoh: G lalu X (geser hanya sumbu X)**



&#x20; **6) Snap biar presisi (opsional)**



&#x20; **1. Atas viewport, klik ikon magnet (Snap) untuk ON.**

&#x20; **2. Di sebelahnya pilih tipe snap (mis. Vertex).**

&#x20; **3. Saat geser, tahan Ctrl untuk snap.**



&#x20; **7) Simetri kiri-kanan (penting)**



&#x20; **1. Nama bone kiri-kanan harus format .L dan .R jika mau mirror otomatis.**

&#x20; **2. Di Edit Mode, buka menu atas viewport: Armature > Symmetrize untuk copy sisi kiri ke**

&#x20;    **kanan (atau sebaliknya).**

&#x20;    **Kalau nama masih L\_/R\_, symmetrize otomatis tidak seakurat .L/.R.**



&#x20; **8) Cek hasil deform**



&#x20; **1. Kembali ke Object Mode (Tab).**

&#x20; **2. Ubah ke Pose Mode (dropdown kiri atas).**

&#x20; **3. Pilih bone, tekan R untuk rotasi test.**

&#x20; **4. Kalau mesh aneh, lanjut weight paint.**



&#x20; **9) Simpan**



&#x20; **- File > Save (Ctrl+S).**



&#x20; **Kalau mau, berikutnya saya kasih urutan bone mana dulu yang paling efektif digeser untuk**

&#x20; **tangan (Wrist -> Palm -> Thumb -> Index ...) biar cepat rapi dan tidak bikin weight rusak**

&#x20; **besar.**
