# PASRAHPHOBIA_UI Figma Handoff

Build `PASRAHPHOBIA_UI.figma` with this page order:

1. `Visual Direction`
2. `Design System`
3. `Components`
4. `Game Screens`
5. `Effects & Animation`
6. `Icon & Asset Sheet`

Checklist:
- Use local color styles for all palette tokens from the design brief.
- Use local text styles for title, heading, label, body, micro, and numeric data.
- Use auto layout on every component set, modal shell, and list/grid section.
- Build variants for `default`, `hover`, `active`, `disabled`, and `locked`.
- Provide both `1920x1080` and `390x844` frames for every major screen.
- Keep frame/component names in English for Roblox asset mapping.
- Prepare exports at `1x`, `2x`, and `3x`.

Required component sets:
- HUD bars and prompt blocks
- Quickslot frames
- Minimap shells and room cells
- Inventory slots and detail cards
- Ranked badge tiles and star rows
- Royal Pass reward nodes and CTA blocks
- Settings toggles, sliders, and tabs
- Overlays for vignette, glitch, scanline, and PASRAH flash

Export groups:
- `Icons`
- `RarityCards`
- `Screens`
- `Effects`
