# PASRAHPHOBIA UI Package

This package turns the brief in `asset-finder.md` into a Roblox UI handoff package.

Contents:
- `docs/pasrahphobia-ui-ux-brief.md` contains the visual system, icon list, measurements, screen specs, effects logic, Figma structure, asset readiness, and Studio setup notes.
- `exports/Figma/PASRAHPHOBIA_UI_Figma_Handoff.md` is the direct page/component checklist for building `PASRAHPHOBIA_UI.figma`.
- `roblox/src/Modules/*.lua` contains the eight requested ModuleScripts.
- `roblox/src/Shared/UIConfig.lua` centralizes tokens, remotes, rarities, and rank tiers.
- `exports/Roblox Assets/` mirrors the requested asset export folders.

Reference inputs used:
- `Branding.png`
- `branding-icon.png`
- `contoh-royalpass-30d.png`
- `acuan-visual-ui-ux-gui-pasrahphobia-ui.html`
- `asset-finder.md`

Notes:
- No `.figma` binary was generated in this environment. The handoff file and brief define the exact Figma structure to build.
- The supplied images are reference art, not final Roblox-ready exports.
